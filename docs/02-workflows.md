# Work Flow ها — بازی مافیا (v1: مافیای روسی)

*نوشته‌ی لیلا (BA)*

## ۱. Flow ساخت و ورود به روم

```mermaid
flowchart TD
    A[کاربر: ساخت روم] --> B[سرور: تولید RoomCode شش‌رقمی]
    B --> C[کاربر Host وارد Lobby می‌شه]
    D[کاربر دیگر: ورود با RoomCode] --> E{روم باز است؟}
    E -- نه (پر/شروع‌شده) --> F[خطا: قابل ورود نیست]
    E -- بله --> G[افزودن به Lobby]
    G --> H{تعداد بازیکن >= حداقل؟}
    H -- بله --> I[Host: دکمه‌ی شروع فعال می‌شه]
    H -- نه --> G
    I --> J[Host: Start Game]
    J --> K[سرور: تخصیص نقش‌ها + ورود به فاز شب]
```

**قوانین سیستمی:**
- حداقل بازیکن برای «مافیای روسی»: ۶ نفر (نسبت پیشنهادی مافیا:شهر ≈ ۱:۳)
- فقط Host می‌تونه بازی رو استارت کنه
- بعد از Start، RoomCode دیگه قابل‌استفاده برای ورود نیست (Room.Status = InProgress)

## ۲. Flow فاز شب (فقط شب اول — طبق قانون سناریو)

```mermaid
sequenceDiagram
    participant S as سرور
    participant M as بازیکنان مافیا
    participant C as بازیکنان شهروند

    S->>M: شروع فاز شب (Phase=Night, Round=1)
    S-->>C: نمایش صفحه‌ی "شب است، منتظر بمانید"
    M->>S: انتخاب قربانی (NightAction)
    Note over M,S: هر عضو مافیا می‌تونه تا پایان تایمر نظرش رو عوض کنه
    S->>S: اجماع رأی مافیا (اکثریت یا انتخاب Don در نسخه‌ی ساده: اولین رأی ثابت)
    S->>S: پایان تایمر شب → قفل شدن اکشن‌ها
    S-->>M: انتقال به فاز روز
    S-->>C: انتقال به فاز روز + اعلام قربانی
```

**قوانین سیستمی:**
- تایمر پیش‌فرض فاز شب: ۴۵ ثانیه
- اگه مافیا هیچ انتخابی نکنه تا پایان تایمر → هیچ‌کس نمی‌میره (no-kill night)
- از شب دوم به بعد: فاز شب صرفاً یک «مکث نمایشی» کوتاهه، اکشن کشتن غیرفعاله (طبق قانون سناریوی مافیای روسی)

---

## ۳. Flow فاز روز و رأی‌گیری

```mermaid
flowchart TD
    A[شروع فاز روز] --> B[اعلام قربانی شب قبل - اگر باشد]
    B --> C{بازی تمام شده؟}
    C -- بله --> Z[Flow پایان بازی]
    C -- نه --> D[فاز بحث - تایمر ثابت]
    D --> E[فاز رأی‌گیری علنی]
    E --> F[هر بازیکن زنده یک رأی می‌دهد]
    F --> G{اکثریت مطلق؟}
    G -- بله --> H[حذف بازیکن رأی‌آورده]
    G -- نه، تساوی --> I[دور دوم رأی فقط بین نفرات مساوی]
    H --> J{بازی تمام شده؟}
    I --> F
    J -- بله --> Z
    J -- نه --> K[شروع فاز شب بعدی]
```

**قوانین سیستمی:**
- رأی روز **علنیه** — هر بازیکن می‌بینه کی به کی رأی داده (برخلاف اکشن شب که مخفیه)
- تساوی در دور دوم هم اگه ادامه پیدا کنه → آن روز کسی حذف نمی‌شه (skip)

---

## ۴. Flow بررسی شرط پایان بازی

بعد از **هر** حذف بازیکن (چه در شب، چه در روز) این چک اجرا می‌شه:

```mermaid
flowchart LR
    A[بازیکنی حذف شد] --> B{تعداد مافیای زنده == 0؟}
    B -- بله --> C[برد شهر]
    B -- نه --> D{تعداد مافیای زنده >= تعداد شهروند زنده؟}
    D -- بله --> E[برد مافیا]
    D -- نه --> F[ادامه‌ی بازی]
```

---

## ۵. Flow قطعی اتصال و بازگشت (Reconnect)

```mermaid
flowchart TD
    A[بازیکن قطع می‌شود] --> B[Player.ConnectionState = Disconnected]
    B --> C[Player.Alive بدون تغییر می‌ماند]
    C --> D{در حال فاز اکشن است؟}
    D -- بله و نوبت اوست --> E[تایمر فاز ادامه دارد؛ اکشن به‌صورت پیش‌فرض ثبت نمی‌شود]
    D -- خیر --> F[هیچ اثری ندارد]
    G[بازیکن دوباره وصل می‌شود] --> H[سرور state فعلی را کامل resync می‌کند]
    H --> I[Player.ConnectionState = Connected]
```

**قوانین سیستمی:**
- قطعی اتصال هرگز باعث حذف خودکار از بازی نمی‌شه (جلوگیری از سوءاستفاده‌ی «قطع عمدی برای فرار از رأی»)
- اگه Host قطع بشه، مالکیت Host به‌صورت خودکار به نفر بعدی در Lobby منتقل می‌شه (فقط قبل از Start)

---

## ۶. Flow پایان بازی

```mermaid
flowchart TD
    A[شرط برد محقق شد] --> B[سرور: قفل کردن تمام اکشن‌ها]
    B --> C[افشای تمام نقش‌ها برای همه‌ی بازیکنان]
    C --> D[نمایش صفحه‌ی نتیجه + آمار بازی]
    D --> E{Host: بازی مجدد؟}
    E -- بله --> F[ساخت GameSession جدید با همان Room/Lobby]
    E -- نه --> G[بستن Room]
```
