# چی دیگه لازمه؟ — تحلیل شکاف با پلتفرم‌های موجود

*نوشته‌ی لیلا (BA)* — بر اساس تحقیق روی پلتفرم‌های Mafia/Werewolf آنلاین (Werewolf Online، Werewolf Voice، Plato) و اصول طراحی بازی‌های Social Deduction.

## چیزی که همین الان (بعد از این سند) پوشش دادیم
چت + صدا با کانال‌بندی درست (شهر/مافیا/مرده‌ها)، Lobby ظرفیت‌محور.

## Must — بدون این‌ها بازی «قابل‌اعتماد» نیست

| نیاز | چرا |
|---|---|
| **جداسازی کامل چت/صدای مرده‌ها از زنده‌ها** | مهم‌ترین ریسک تقلب — پوشش داده شد در سند ۰۷ |
| **Mute اجباری از سمت سرور، نه client** | client هک‌پذیره؛ اعتماد فقط به سرور |
| **قفل رأی/اکشن بعد از حذف‌شدن** | از قبل در قانون Domain پوشش داده شده (`PlayerAlreadyEliminatedException`) |

## Should — بدون این‌ها تجربه ضعیفه ولی بازی خراب نمی‌شه

| نیاز | توضیح |
|---|---|
| **Mode تماشاگر (Spectator)** | تحقیق نشون داد یکی از رایج‌ترین دلایل نارضایتیه: «بازیکنی که راند اول حذف می‌شه و ۴۵ دقیقه فقط نگاه می‌کنه» — چت/صدای مرده‌ها این رو تا حدی جبران می‌کنه، ولی یه Spectator UI جدا (لیست بازیکنان زنده + رأی‌ها به‌صورت زنده) تجربه رو بهتر می‌کنه |
| **روم خصوصی با رمز** | پلتفرم‌های رقیب همه این رو دارن — برای بازی با گروه دوستان بدون نگرانی ورود غریبه |
| **کنترل‌های میزبان (Kick / Mute اجباری یه نفر)** | برای مدیریت رفتار مخرب (اسپم چت، سکوت عمدی موقع نوبت) |
| **Push-to-talk (به‌جای میکروفون همیشه باز)** | تجربه‌ی صوتی تمیزتر، مخصوصاً موبایل |

## Nice-to-have — بعد از اثبات MVP

| نیاز | توضیح |
|---|---|
| **راوی/گاد صوتی خودکار (Narrator)** | پلتفرم‌های جدید روی این سرمایه‌گذاری کردن — اعلام فاز با صدای ضبط‌شده به‌جای فقط متن، برای تازه‌کارها راحت‌تره |
| **واکنش سریع با ایموجی حین رأی‌گیری** | تعامل بیشتر بدون بهم‌زدن تمرکز بحث |
| **آمار/پروفایل بازیکن (برد/باخت به تفکیک نقش)** | نگه‌داشتن بازیکن برای بازی‌های بعدی |
| **Ranked / Matchmaking عمومی** | در برابر روم خصوصی با کد — برای وقتی گروه دوستان کافی نیست |
| **Replay بازی (چه کسی چی رأی داد، چه زمانی)** | برای یادگیری و حل اختلاف بعد از بازی |

## تصمیم PO — چی وارد Backlog می‌شه

Epic های جدید (۹ تا ۱۲) به لیست backlog اضافه شدن — همه‌شون Must/Should، یعنی قبل از عرضه‌ی عمومی لازمن. Nice-to-have ها عمداً بیرون از v1 موندن (مثل Epic ۸ قبلی) تا اول MVP اثبات بشه.
